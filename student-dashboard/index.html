Method

How this dashboard is designed to run

Design logic

One screen answers three questions per activity — conducted (quantity), liked (quality), outcome (performance) — so advisors stop hunting through documents and ClickUp folders.

Cadence lensDay · Week · Month · Quarter
AudienceAcademic advisor + founder
Two viewsCohort average + per-Alcovian
North-starSyllabus on-track & rigour adherence

In what time

Daily data captureAutomatic (app + wearables)
Weekly advisor review15 min · Monday
Monthly consolidation1 hour · month-end
Quarterly OKR reviewHalf day

Live view updates continuously; the advisor's 15-min Monday slot replaces the current weekly document-writing ritual.

Where it reflects & how data is recorded (minimal human intervention)

Focus time, screen time, feature useApp event stream → N8N → dashboard
Active minutes & recoveryApple/Samsung/WHOOP/Garmin → health sync → N8N
Quizzes, chapters, tasksApp student inputs → ClickUp → N8N
Sessions, workshops, ratingsClickUp (CRM) + post-session form → N8N
Alerts on missed deadlinesN8N rule → message to student + parent + advisor
i
Advisors only review and act; the system collects, scores and alerts. Data from different folders in ClickUp collapses into one templatised record per Alcovian.
